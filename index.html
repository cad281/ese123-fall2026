How to use these guides

Before lab

Read the guide and play with the simulations. Predict your readings so you know when a measurement looks wrong.

During lab

Keep the formula sheet open. Each formula says when to use it and has a worked example with that lab’s parts.

After lab

Try the practice questions (new numbers, same ideas as the quizzes), then follow the report guide for each question.

On your phone

Every page works on a phone. The text-only README version of each lab is on GitHub too.
