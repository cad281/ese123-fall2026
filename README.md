# ESE 123 Lab Guides · Fall 2026

**Home page:** https://cad281.github.io/ese123-fall2026/

Each guide explains **what** you do, **why** it matters and **how** to do it step by step, with live instrument simulations, a formula sheet, practice questions and a report guide.

## How to use them

- **Before lab:** read the guide and try the simulations so you can predict your readings.
- **During lab:** keep the formula sheet open.
- **After lab:** do the practice questions (same concepts as the quizzes, new numbers) and follow the report guide.

These guides add to the official handouts on Brightspace and don't replace them.
